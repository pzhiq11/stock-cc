# 当前设计

StockLens面向个人桌面网页使用，仅分析A股；辅助高抛低吸、建仓与减仓，不接入账户和自动交易。首页默认股票，可搜索和维护最多20只常看股票，同时高频监控一只股票。保留分时、日K、公司资料、AI投研、竞价研判、收盘复盘与下一交易日条件计划。

## 简单架构

Next.js负责网页、Route Handlers和请求触发采样；Prisma连接当前环境的PostgreSQL。业务表只有四张：

| 表 | 保存内容 |
| --- | --- |
| AppSetting | 最近股票、提醒偏好、加密模型配置 |
| Watchlist | 股票代码、名称、显示顺序 |
| DailySignal | 当日确认点位、冻结输入、失效事件、覆盖情况、策略版本、有界请求状态与租约 |
| AnalysisReport | 结构化报告、证据快照、模型、日期和版本 |

报价、分时、日K、公司资料按需取免费接口，使用短缓存与请求合并，不另外建行情数据库。腾讯提供报价、可见买卖盘、指数与日K；东方财富提供分钟OHLC、公司与公告索引；可选AKTools提供AKShare扩展。公开接口由适配层处理，缺失数据明确展示。

本地连接本地库，服务器连接线上库，无额外环境路由。用Prisma迁移建表，seed只初始化缺失基础记录。模型自动使用界面配置，其次环境变量，无配置则禁用AI。配置加密密钥优先使用CONFIG_ENCRYPTION_KEY，不填使用项目固定默认密钥；密文记录来源，无本地文件依赖。环境变量无效时报错，不静默更换密钥。旧本地文件密文需一次性迁移或重新输入API Key保存。

## 交易时段与刷新

客户端和接口共用上海时区、交易日历与时段定义。09:15–11:30、13:00–15:00更新报价，连续交易时段才产生实时点位；竞价采样用于竞价报告。

午休与休市不循环请求行情。页面首次加载、手动刷新仍可取数据。11:31、15:01分别取得最终分钟；其他时间由本地时钟等待开市。周末与官方节假日跳过，服务器返回的日历可以覆盖内置规则，未核验年度暂停点位。日历结果按日期缓存，扩展接口离线时也不会在每秒循环重试。

移除启动钩子与Node定时器。页面点位请求合并执行一轮采样；没有页面请求时不采样、不生成报告，也不进行自主重试。页面隐藏或关闭后停止轮询，再次打开时按当时可用的历史分钟因果补点。竞价结果可用后、15:10后的股票页面仅对当前股票发起一次报告请求；离开页面后不再发起下一项。报告请求用幂等键去重，失败保留手动重试。

## 因果点位流程

1. **历史背景**：以已完成分钟OHLC、成交额、VWAP和匹配历史指数计算布林、RSI、KDJ、MACD、ATR、ADX与趋势。指标由technicalindicators和因果计算层提供。
2. **即时触发**：每个新有效报价只投影当前未完成周期，不制造已完成K线。即时价格、盘口、量价速度与已知分钟背景合并评分，无需等待下一分钟、反转确认或后续报价。
3. **行情分类与硬性过滤**：V5以已完成五分钟趋势与效率判断大方向，结合分钟斜率、EMA和ADX区分震荡与趋势。震荡看边界拒绝/承接；上涨优先回踩支撑、下跌优先反弹阻力；逆势机会须有充分价格与转折证据，强趋势还须同时看到明确突破失败/破位收复、动量衰竭及量价支持。报价和指数必须及时且因果可用。噪声规模波动、空间不足、机会已经明显走过、配额耗尽和证券状态未支持仍属于硬性过滤。
4. **规则评分**：位置20、当前波段与空间20、价格转折与量价40、趋势10、当时指数10。数据有效与时序正确属于硬过滤，不给免费分。RSI、KDJ与MACD合并为一个动量组；已观察到的突破失败/破位收复可作为替代转折路径，与动量择强，不要求滞后指标同时反转。价格转折组包含价格响应22分、转折质量10分、量价8分，并非独立统计概率。影线需同时具有ATR尺度和收盘拒绝力度；一档挂单必须结合价格响应。波段起点来自截至当时已观察的最近波段转换。目标取本波起点或更近的已验证且未被破坏的结构；VWAP只有已有实际承接/拒绝才作为空间障碍，布林中轨仅作位置参考，不为提高风险收益比故意越过已知障碍。波动尺度为1.5ATR与近60分钟完整五分钟区间中位数的0.75倍择大；波段规模至少1个尺度、剩余空间至少0.5个尺度、收益风险比至少1.5，距已知极值回撤超过0.6个尺度跳过。总分至少85且所有过滤通过才进入AI复核。
5. **AI最终判断**：只向模型提供触发时冻结快照。明确拒绝则不标点；批准或AI不可用则按量化结果继续。AI复核最多5秒，不重试AI；当前点位请求等待复核和保存后返回，前端报价请求可以独立继续。
6. **保存前再核验**：最新报价过期、事件超过30秒、突破失效线或机会空间明显变化时放弃。保存触发报价位置及实际确认时间，不把确认时价格回画成先前极值。
7. **不可改写**：点位按收到报价的时间与当时报价冻结；后续仅追加失效事件。每侧每天最多3点，无补满要求。同一偏离机会只触发一次，退出该偏离区后才重新具备资格，没有固定时间间隔或固定价差。

历史补点按已完成分钟收盘时刻和收盘价判断，只读取该时刻及之前的数据。分钟源未提供完整的起止与到达保证，因此保守使用原始标签后一分钟作为完成时刻；分时曲线优先使用同一OHLC源并绘在相同完成时刻，保留原始时间标签，不前移点位。OHLC不可用时回退腾讯分时展示，点位回放保持暂停。缺少历史秒级盘口和当时AI结果，标记为分钟近似回放，不调用当前模型，不按全天表现筛选早期点。分钟决策流与报价决策流各自按时间推进、共享已处理机会和配额；监控期间新完成分钟线在30秒有效期内也可触发AI复核，不能绕过AI生成实时点。较晚报价的候选不能进入较早分钟判断。重新打开时重建分钟回放，补足空档；已有点位和AI否决继续抑制同次偏离。接口按股票合并请求，切换不取消此前已发出的有限历史回放；背景过期先等待刷新。分钟最高分与过滤原因保存在原覆盖字段中，无新增表。

历史缺开盘价只停用依赖开盘价的影线证据，不合成开盘价，也不否定仍有效的收盘与成交信息；缺必要成交或当时指数仍暂停该分钟标点。界面分别统计每侧检查分钟、预热不足、数据受限、候选、达到85分、通过过滤和同时满足次数，列出重叠的过滤原因、最高候选及通过过滤的最高候选。量化达标次数不等于保存点数，还要遵守结构去重、实时AI复核和数据库配额。

V5首次请求自动升级当天策略，清理旧版引擎、候选、回放统计及AI否决状态；保留竞价快照、报告租约和所有已确认点。已确认记录保留其原策略版本与当天占用配额。回放某一分钟时，较晚点位不提前消耗当时的判断配额或抑制候选；保存仍按全日已确认记录限制每侧最多3点。混合版本的已保存点并非清空历史后的全量新策略回测。数据库通过行锁、事件去重和快照核验保证配额及因果约束。板块时序未核验时不评分，一档买卖盘只代表可见盘口，不能当作完整订单流。

## 模型兼容与报告

使用官方OpenAI SDK的Chat Completions接口，支持OpenAI、DeepSeek和兼容代理的自定义Base URL。官方OpenAI根地址自动补`/v1`，完整聊天路径自动转为接口前缀。没有temperature等非必要参数；GPT推理模型使用包含思考预算的`max_completion_tokens`，DeepSeek使用相应思考开关。

连接测试验证最终正文。点位复核要求`approve/reject`结构，5秒超时回退量化；报告需要有来源ID的JSON。只提取最终内容与数值token统计，不保存推理链、API Key或供应商任意错误正文。连接、权限、限流、截断、空正文、协议格式异常分别提示。

竞价研判可随时触发，历史竞价接口采用与 AKShare stock_zh_a_hist_pre_min_em 同源的东方财富数据，只提取9:15至9:30之前的分钟标签，按标签后一分钟保守确认可用。需要已撮合成交结果，匹配同一截止时刻的指数和最相关行业板块；缺失时不使用盘中行情补齐。首次有效快照冻结在现有 DailySignal.coverage.auction 中，报告生成时间与竞价数据截止分别标明，不引入当日日K、后续分时、公告或点位。收盘复盘要求完整当日分时。下一交易日计划使用核验日期及偏强、震荡、偏弱三个条件情景。报告保留输入截止与证据版本，拒绝未提供的来源和价格。

## 运行边界

支持单实例网页服务与Vercel请求实例；浏览器关闭或隐藏后停止采样。已由页面发出的有限请求可能完成，但不会启动后续采样或无人值守报告。重新打开页面用分钟历史补足空档，无法复原未观察到的秒级报价与AI决策。免费源的时效、网络和模型速度决定实际延迟。工程评分未经样本外准确率校准，85分不是85%概率，分钟历史回放不能证明实时策略胜率。


## 请求实例与数据库状态

点位流程为前端轮询、后端读取状态和取行情、因果计算、AI复核、数据库校验保存、返回前端显示。DailySignal.runtime保存最近240根分钟背景、100条股票报价、20条指数报价及两个引擎候选/处理状态；分钟流共用报价流背景。每轮恢复数据库状态，确认点位仍以独立highPoints/lowPoints为准，不依赖globalThis业务状态。

数据库短事务申请股票/交易日/任务租约，网络和AI期间不持有长事务。点位租约90秒、接口60秒；报告租约210秒、接口180秒。进程中断后，下个页面请求接管过期租约；所有状态提交和新增点位验证租约所有者，旧请求不能覆盖新状态。AI否决与恢复状态一起保存，尚未完成的预留在下一请求释放。各类报告分开加租约，重复请求返回202，GET从数据库读取进度。没有调度器、后台队列或自动重试；有限工作都在响应之前完成。

数据库连接池每实例最多3条连接，连接等待10秒、空闲5秒；Vercel使用attachDatabasePool释放暂停前空闲连接。本地和云端均只通过DATABASE_URL选择数据库，迁移时临时传直连URL，应用使用连接池URL。配置加密密钥优先环境变量、否则项目固定默认值，无文件依赖。详细上线步骤见README中的Vercel指南。
